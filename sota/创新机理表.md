| **故事** | **水下三维重建的关键，不仅是恢复物体原本的颜色，还要区分哪些视觉信息来自真实场景，哪些来自水体，并准确描述水体对光传播的影响。**<br><br>现有一些水下三维重建方法利用物理成像模型，将场景自身颜色与水体造成的颜色衰减、散射影响进行分离，以同时完成水下场景重建和清晰场景恢复。这类方法能够在一定程度上改善水下颜色失真和能见度下降问题，但在复杂水体环境中仍然存在两个关键困难。<br><br>**第一个问题是，真实场景与水体成分容易在三维表示中发生混杂。**水下远处物体通常表现为蓝绿色明显、对比度低、纹理模糊，与纯水背景和水雾区域十分相似。当模型无法准确区分这些成分时，可能使用大量三维高斯点拟合水雾，也可能在去除水体影响时错误削弱真实物体，造成清晰结果中水雾残留、远景结构缺失等问题。<br><br>**第二个问题是，水体光学特性难以通过统一参数准确描述。**一些方法主要根据观察方向和传播距离估计水体造成的衰减与散射，能够表达整体水色变化，但难以充分描述不同空间位置的局部水体差异。实际上，光线从不同物体传播到相机时，可能经过浑浊程度不同的水域，因此即使传播距离相近，受到的水体影响也可能存在差异。<br><br>针对这两个问题，我的方法提出**多视角水体—场景物理解耦**和**空间异质水体路径积分传输**两项创新。前者从三维场景表示入手，区分真实场景与水体成分；后者从水下光学成像入手，描述空间变化的水体属性及其沿光路产生的累积影响。两项创新相互配合，使模型既能减少虚假水体结构与真实场景的混杂，又能更加准确地恢复复杂水下环境中的颜色和结构。 |
| **难点** | **难点一：水体与远处真实物体具有高度相似的视觉特征。**<br><br>水体散射会使远处物体逐渐失去原有颜色和纹理，呈现出与水雾、纯水背景相近的蓝绿色外观。因此，仅依靠颜色、亮度或深度，很难判断一个区域究竟属于真实物体，还是由水体影响形成的视觉内容。若判断过于激进，容易误删真实结构；若判断过于保守，又难以有效去除水雾。<br><br>**难点二：单张图像无法可靠确定三维成分归属。**<br><br>真实物体可能在某个观察角度下表现得十分模糊，却在另一个角度下呈现出清晰的结构。仅根据单个视角生成水体区域判断，无法保证其在三维空间中始终成立。因此，如何将不同视角中的信息对应到同一三维高斯点，并利用持续积累的证据提高判断可靠性，是实现稳定物理解耦的重要困难。<br><br>**难点三：空间变化的水体与场景颜色容易相互干扰。**<br><br>当水体参数能够随空间位置变化时，模型获得了更强的表达能力，但也可能错误地使用水体变化解释物体本身的颜色和纹理。例如，某个区域颜色偏暗，既可能来自物体本身，也可能来自更强的水体衰减。如果缺少合理限制，水体模型和场景模型可能相互替代，导致物理解释不稳定。<br><br>**难点四：必须兼顾清晰场景恢复与原始水下成像的一致性。**<br><br>减少蓝绿色水雾并不意味着重建一定更准确。如果模型通过过度压暗颜色、削弱透明度或错误调整水体参数来获得更干净的清晰结果，就可能造成物体细节损失和水下重建失真。因此，水体去除必须建立在可靠的场景区分与合理的光学传输基础上。 |
| **创新点1** | ### 多视角水体—场景物理解耦<br><br>**核心思想：利用多视角持续积累的证据，在三维高斯层面区分真实场景成分与水体成分，避免两者在场景表示中相互混杂。**<br><br>现有一些方法主要通过图像颜色、深度或前景分割结果判断哪些区域可能属于水体。然而，二维图像中的水体特征往往与远处真实物体高度相似，而且同一位置在不同视角下可能呈现出不同的外观。若直接根据单视角判断来决定三维高斯点的保留与去除，就容易出现水雾残留和真实结构误删的问题。<br><br>针对这一问题，我的方法不再将每个高斯点完全视为真实场景，而是对其所包含的**真实场景成分和水体成分进行联合估计**。<br><br>首先，模型综合分析深度、颜色、纹理和边缘等信息，初步判断图像中的哪些区域更可能属于真实物体，哪些区域更可能受到水体主导。例如，具有明显纹理、结构边缘和深度变化的位置，会获得更强的场景证据；颜色接近水体背景、缺乏明显结构的区域，则会获得更强的水体证据。<br><br>其次，模型并不直接根据这些二维判断删除高斯点，而是结合真实的遮挡关系，将不同图像区域提供的证据分配给实际参与成像的三维高斯点。这样，某个高斯点是否属于水体，不再只取决于它投影到图像中的位置，而是取决于它在当前视角下对图像内容产生了多大贡献。<br><br>进一步地，模型会持续记录同一个高斯点在不同视角下获得的场景证据和水体证据，并结合观察次数、视角差异以及三维结构可靠程度进行综合判断。只有当多个视角持续提供一致证据时，才逐渐确定其主要成分；对于证据不足或相互矛盾的高斯点，则保留不确定性，避免过早作出错误判断。<br><br>最后，在场景表示上，模型没有采用直接删除疑似水体高斯点的方式，而是**将高斯点的真实场景贡献与水体贡献进行柔性解耦**。在恢复清晰场景时，主要保留可信的真实场景成分，并逐渐减弱水体成分；在重建原始水下图像时，则仍然保留必要的水体影响和遮挡关系。<br><br>**这一创新的关键在于：将传统依赖单张图像的水体判断，转化为具有多视角一致性约束的三维成分解耦。**它不仅能够减少由水雾形成的虚假高斯结构，还能够利用跨视角证据保护远处真实物体，从而缓解水体去除与场景完整性之间的矛盾。 |
| **创新点2** | ### 空间异质水体路径积分传输<br><br>**核心思想：将水体表示为空间中缓慢变化的光学介质，并沿相机与场景点之间的传播路径累积水体造成的颜色衰减和散射，实现对复杂水下成像的统一描述。**<br><br>现有一些基于物理成像的水下重建方法，主要通过观察方向、场景深度和水体光学参数计算颜色衰减与散射。这种处理能够较好地描述相对均匀的水体环境，但当不同空间位置具有不同的浑浊程度、散射强度和颜色衰减特性时，仅依靠整体水体参数难以准确解释真实成像。<br><br>针对这一问题，我的方法提出**空间异质水体路径积分传输**，将水体的空间变化与光线传播过程统一建模，而不是把空间水体估计和光路计算当作两个相互独立的任务。<br><br>具体来说，模型首先学习场景中的整体水体光学特征，作为描述环境水色、衰减和散射的基础。在此基础上，利用一个较为粗糙且连续平滑的三维水体表示，对不同空间位置的局部水体属性进行小幅调整。这样既能够表达局部水体差异，又不会让水体表示具有过强的自由度，避免错误地将物体纹理和颜色细节吸收到水体模型中。<br><br>在实际渲染时，模型沿相机到场景点的传播路径读取不同位置的水体属性，并将各位置产生的颜色衰减与散射逐段累积。也就是说，**一个场景点最终呈现出的水下颜色，不仅由它与相机之间的距离决定，还由光线沿途经过的水体状态共同决定。**<br><br>例如，两处物体距离相机可能相近，但其中一条光路经过较为清澈的水域，另一条光路经过更加浑浊的区域。通过沿路径累积不同位置的水体影响，模型能够为这两处物体计算出不同的光学传输结果，更加符合真实水下环境的成像规律。<br><br>此外，为了避免水体属性和真实场景颜色相互混淆，我的方法还将创新点1提供的解耦信息用于指导水体学习。模型更加重视具有可靠水体证据的自由水空间，并限制真实物体附近不合理的水体变化，使空间水体表示更符合实际的三维分布。<br><br>在优化过程中，模型采用交替更新的方式，分别调整场景表示与空间水体属性，减少二者同时解释同一成像误差的问题。同时，通过限制水体参数变化幅度及空间变化的复杂程度，保持水体光学描述的稳定性。<br><br>**这一创新的关键在于：将水体空间分布直接融入光学传输计算，使局部水体变化能够沿真实光路产生连续累积的成像影响。**相较于主要依赖整体水体参数的处理方式，它能够更加准确地描述复杂环境中不同位置、不同传播距离下的颜色衰减和散射，并降低水体模型与场景颜色之间的相互干扰。 |
| **配套训练保护** | **核心目的：在提高水体去除能力和光学表达能力的同时，保护真实场景结构与水下成像结果。**<br><br>水体与场景解耦过程中，一个重要风险是过度去除。部分方法可能通过减弱颜色、降低透明度或删除不确定结构来获得更干净的清晰结果，但这种处理也可能使真实物体变暗、边缘受损或远景消失。<br><br>为此，我的方法根据不同区域的特点进行有区别的约束。对于具有较高可信度的纯水区域，抑制不必要的三维高斯占据，减少模型利用虚假结构拟合水体背景的情况。对于附着在真实物体表面的蓝绿色水雾，重点减少水体颜色残留，同时保护物体纹理和边缘。<br><br>对于具有明确结构证据的真实场景区域，强化原始水下图像的颜色、亮度和细节一致性，避免模型为了追求清晰结果而破坏真实成像。对于水体与物体之间的过渡区域，则保留更加保守的判断，以降低黑边、结构断裂和局部颜色异常的风险。<br><br>与此同时，对空间水体参数的调整幅度和变化范围进行约束，防止模型通过不合理的水体参数变化掩盖场景表示中的误差。<br><br>因此，这些训练设计并不是独立的第三项创新，而是围绕两项核心创新建立的**场景保真与物理约束**，保证模型在提高水体解耦和光学传输能力的同时，尽可能保留真实物体的结构、颜色和细节。 |
| **对模型的理解** | **我的方法围绕水下三维重建中的两个核心问题展开：水体与场景为什么难以分开，以及空间中不均匀的水如何影响光线传播。**<br><br>对于第一个问题，传统的图像级水体判断很难可靠地区分远处真实物体与水雾，而且不同视角之间可能出现不一致。我的方法通过**多视角水体—场景物理解耦**，将场景与水体的区分提升到三维高斯层面，通过多视角持续积累证据，对高斯点中的真实场景成分和水体成分进行逐步、保守的解耦。它解决的不是简单的图像分割问题，而是**三维表示中真实场景与水体混杂的问题**。<br><br>对于第二个问题，使用统一水体参数难以充分描述复杂环境中的空间差异，而过度自由的水体表示又容易错误吸收场景颜色。我的方法通过**空间异质水体路径积分传输**，在保持水体空间变化平滑、有限的基础上，沿光线传播路径累积不同位置产生的衰减和散射，使水体参数与真实物理传播过程直接联系起来。它解决的不是单纯增加水体参数数量的问题，而是**如何在具有合理物理约束的前提下表达空间非均匀水体的成像影响**。<br><br>更重要的是，这两项创新并不是简单叠加，而是相互促进。水体—场景解耦能够提供更加可靠的水体空间信息，使光学传输建模不容易受到真实物体干扰；更加准确的水体传输又有助于解释水下颜色变化，降低模型将水体影响错误表示成场景结构的可能性。<br><br>因此，整个方法形成了**“三维成分解耦—空间水体传输—场景保真约束”**的完整研究思路。其中，第一项创新重点解决三维场景的**表示准确性**，第二项创新重点解决水下光学过程的**成像准确性**，两者共同服务于复杂水下环境中的真实场景恢复。 |

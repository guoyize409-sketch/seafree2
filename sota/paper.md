| **故事** | **水下三维重建的关键，不仅是恢复物体的颜色，还要区分真实表面与水体各自对图像的贡献，并描述光线穿过不同水域时产生的累积退化。**<br><br>现有一些水下三维重建方法利用物理成像模型，将场景颜色与水体造成的衰减、散射进行分离，以同时完成水下图像重建和清晰场景恢复。这类方法能够解释整体水下退化，但在复杂环境中仍面临两个问题。<br><br>**第一个问题是，水体外观容易被错误地编码为真实表面的几何和颜色。**远处物体经过水下传播后，往往与自由水背景具有相似的蓝绿色、低对比度外观。若缺少可靠的三维成分区分，模型可能使用具有颜色和透明度的高斯拟合水雾；若对疑似水体区域统一压暗或削弱占据，又可能损伤真实远景。仅区分图像中的水体区域还不够，还需要使这种区分落实到高斯的辐射贡献、清晰表面渲染和训练过程。<br><br>**第二个问题是，局部水体变化难以与真实场景外观稳定分离。**主要依赖观察方向和传播距离的水体模型，难以充分描述不同光路经过的局部水域差异；表达过于自由的空间水体模型，又可能把物体纹理和颜色吸收到介质中。<br><br>针对这两个问题，本方法提出**物理可辨识的表面—水体分流重建（M1）**和**有界异质水体路径积分传输（M2）**。M1将多视角三维归属、表面与介质辐射分流、独立表面渲染和区域化表面约束统一起来，重点解决真实结构与水体外观在三维表示中的混杂。M2以受约束的空间水体场描述局部光学差异，并沿传播路径累积其作用，重点解决空间非均匀水体的成像表达与外观混淆问题。 |
| **难点** | **难点一：水体与远处真实物体具有相似的视觉特征。**<br><br>蓝绿色、低纹理和弱边缘既可能来自自由水体，也可能来自受到强散射影响的真实物体。仅依赖单张图像的颜色或深度判断，很难同时避免水雾残留与真实结构误删。需要结合遮挡关系，将不同视角的证据持续对应到同一个三维高斯，并对证据不足的成分保留不确定性。<br><br>**难点二：自由水、附着水幕和真实表面需要不同的恢复方式。**<br><br>自由水区域应减少虚假的表面占据和内禀颜色；附着在物体上的水色残留应受到抑制，同时保留纹理；可信表面则需要保护颜色与边缘。还需要重新计算清晰表面之间的遮挡和透射，避免水体承载高斯在清晰输出中遮挡真实物体。<br><br>**难点三：局部水体变化与物体固有外观容易相互替代。**<br><br>同一处颜色变化可能来自表面材质，也可能来自光路中的衰减和散射差异。空间水体场必须具有足够的表达能力，又要受到空间平滑、均值和幅度限制，减少将纹理误当作介质变化的可能性。<br><br>**难点四：场景恢复与水体估计需要合理分工。**<br><br>若高斯外观、全局水体参数和局部介质场同时自由调整，就可能共同补偿同一成像误差。需要通过责任证据区分监督区域，并将表面更新与空间水体更新分开进行，使清晰场景恢复与水下观测解释保持一致。 |
| **创新点1** | **物理可辨识的表面—水体分流重建（M1）**<br><br>**核心思想：利用多视角证据确定高斯中的表面与介质份额，再通过独立表面渲染及与之对应的区域化约束，联合处理虚假水体占据、附着水色残留和真实结构保护。**<br><br>现有一些方法通过二维颜色、深度或分割结果识别水体区域，但二维判断难以直接保证三维归属的一致性，也难以决定同一高斯应如何参与水下图像和清晰图像的形成。本方法为高斯建立持续更新的表面—介质归属状态，将二维证据转化为三维载体的成分依据。<br><br>首先，模型综合深度、颜色、纹理和边缘线索形成训练证据，结合实际遮挡与成像贡献，将证据分配到参与渲染的高斯上。模型持续积累表面证据、介质证据和观测量，并结合视角覆盖、视差及结构可靠性进行保守判断。归属状态通过显式证据积累更新；对观察不足或证据矛盾的高斯，保留不确定性。该状态还用于高斯生长与保守清理过程，使高斯的生命周期与其成分证据相协调。<br><br>其次，模型将同一高斯的辐射贡献分配给表面流与介质流。水下图像合成保留总不透明度和必要的遮挡关系，表面份额承载经水体传输后的物体辐射，介质份额承载水体辐射。恢复清晰场景时，模型根据表面份额分解光学厚度，并执行**独立的表面不透明度光栅化**，重新计算表面之间的遮挡和透射。训练与推理使用一致的表面渲染路径，使清晰输出中的表面颜色和占据具有直接的训练对象。<br><br>进一步地，模型围绕这一可微表面分支建立七种相互配合的调节机制：在可信自由水区域抑制虚假的表面占据；在水体过渡区域限制过高的表面透明度累积；对空水区域的表面内禀颜色施加零贡献要求；根据残余水体证据抑制表面蓝绿色偏色；在附着水幕区域进一步减弱水色残留；以未分流内禀图像提供的固定细节参照保护表面纹理；在可信且无明显水幕附着的表面区域保护其内禀颜色。空水区域的颜色清除由统一的表面零贡献机制承担，避免重复约束同一输出。<br><br>这些区域权重在训练中作为固定证据使用，被约束的表面颜色和不透明度保持可微，从而直接优化高斯的外观、几何与占据。M1目标在训练步数达到500后启用，并在空间场更新步之外执行。**M1的创新在于让“三维归属—辐射分流—独立表面成像—表面条件训练”保持一致，使水体去除与真实表面保护在同一个重建机制中协调进行。** |
| **创新点2** | **有界异质水体路径积分传输（M2）**<br><br>**核心思想：在方向相关的全局水体模型之上，以低频、零均值且幅度有界的三维介质残差表达局部水体变化，再沿相机到场景高斯的传播路径累积衰减与散射。**<br><br>现有一些基于物理成像的水下方法，主要根据观察方向和传播距离描述水体退化，能够表达整体水色，却难以区分距离相近、所经水域不同的光路。直接增加自由的空间颜色表示则容易混淆介质变化与物体纹理。本方法将空间表达限制在具有明确光学含义的水体变化上，使局部场通过传输过程参与成像。<br><br>首先，方向相关的全局水体模型提供环境光、衰减和后向散射的基础参数。在场景范围内建立紧凑三维宏观场，以四个通道控制介质密度、水体光谱类型、相对后向散射比例和环境光变化。空间场经过平滑处理并移除直流分量，使整体水体外观由全局模型承担；局部变化通过有界映射调节光学参数，限制空间场吸收物体高频纹理的能力。<br><br>其次，模型在相机视锥中沿传播方向分段读取水体属性，建立光学传输前缀，并根据各高斯所在的投影位置与距离查询累积传输，计算其直达光透射和后向散射辐射。不同路径经过的局部水体共同决定退化程度，因此即使物体到相机的距离相近，也可以获得不同的传输结果。背景辐射同样通过相应的空间传输计算参与水下合成。<br><br>为使空间水体估计保持独立，M2在场的定义域内采用统一的自由空间支持，不使用M1载体后验更新空间支持网格。其区域侧重来自共享二维训练证据：自由水和残余水幕区域获得更高的重建权重，不确定区域的权重受到抑制，同时保留其他有效区域的基础贡献。这样，M2可在不依赖三维载体归属更新的情况下接受水下观测监督。<br><br>在优化过程中，模型采用固定阶段的交替更新：在第15,000至22,999步之间每四步安排一次空间场更新，共2,000个场更新槽位。场更新时固定高斯、全局水体预测器、校准器和相机，仅根据**实际路径积分渲染图像与水下观测之间的责任加权绝对误差**调整空间场，并通过**三维空间平滑**与**残差幅度约束**限制局部变化；其他更新步骤用于场景与全局水体参数优化。空间场允许保持接近均匀水体的状态，不强制生成局部差异。<br><br>**M2的创新在于将受约束的空间介质表示、逐路径光学累积和场专属优化统一起来，在表达非均匀水体的同时，限制介质与真实表面外观之间的相互替代。** |
| **配套训练保护** | **核心目的：为表面恢复和空间水体估计提供一致的训练证据，并维持水下观测与场景结构的基本一致性。**<br><br>模型从训练图像、伪深度及渲染信息中构建自由水、残余水幕、真实场景和不确定边界的二维软责任证据。这些证据作为M1和M2共同使用的训练依据，分别指导表面区域约束与空间场重建加权；二维证据生成与M1持续积累的三维载体归属承担不同职责。<br><br>在基础优化中，模型保留水下图像重建、粗粒度伪深度约束和背景水体监督。背景监督根据可信水体责任选择区域，并保留基于伪深度前景掩膜的回退方式。方向条件水体形成校准器对环境光及光学系数作受限调整，同时通过校准幅度正则限制偏移，帮助全局水体参数与观测相协调。<br><br>表面细节和颜色保护由M1内部的表面分支机制承担，空间平滑和残差幅度控制由M2内部的介质机制承担。共享训练部分提供二维责任证据、基础观测约束和水体参数校准，与两项核心机制共同完成优化分工。 |
| **对模型的理解** | **本方法围绕两个问题展开：哪些三维成分应作为真实表面恢复，以及光线沿途经过的非均匀水体应如何影响成像。**<br><br>对于第一个问题，M1通过持续积累多视角证据确定高斯的表面与介质份额，将归属信息落实到辐射分流和独立表面渲染，并对表面占据、内禀颜色、水色残留、纹理及可靠表面实施有区别的调节。它重点解决真实场景与水体外观在三维载体中的混杂，以及去水过程中结构和细节的保护问题。<br><br>对于第二个问题，M2以全局水体参数为基准，引入平滑、有界的空间介质变化，通过沿光路的累积传输解释水下颜色，并以场专属更新控制局部水体与场景外观的分工。它重点解决局部水体差异的光学表达，以及水体参数对真实物体纹理的错误吸收问题。<br><br>两项机制共用二维训练责任证据，分别处理三维表面归属与空间介质传输。M2的空间支持不依赖M1的三维归属更新，使二者具有清晰的功能边界。整体形成**“多视角表面—介质分流重建—有界空间水体传输—责任引导优化”**的方法框架，共同服务于水下观测重建和清晰场景恢复。 |
